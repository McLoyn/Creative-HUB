# Ekraf Tuban – Prototipe Tuban Creative Hub

React + Vite, siap deploy ke Vercel. Data contoh ada di `src/data.js`.

## Jalankan lokal
    npm install
    npm run dev

## Deploy ke Vercel
    npm i -g vercel
    vercel          # preview
    vercel --prod   # produksi
Atau push ke GitHub lalu Import Project di vercel.com (preset Vite terdeteksi otomatis).
